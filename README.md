# Personal Portfolio Website

## 📌 Overview

This repository contains my personal portfolio website, designed to showcase my skills, projects, education, and professional background. The portfolio is fully responsive and built with modern frontend technologies, focusing on clean UI and performance.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Clean and modern UI
* Dedicated sections for About Me, Skills, Projects, and Education
* Easy to customize and extend
* Fast build and optimized performance

## 🛠️ Tech Stack

* **Frontend:** React
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Deployment:** GitHub Pages

## 📂 Project Structure

```
portfolio/
├── public/            # Static assets
├── src/
│   ├── components/    # Reusable components
│   ├── pages/         # Page sections
│   ├── assets/        # Images and icons
│   ├── App.jsx
│   └── main.jsx
├── index.html
├── package.json
└── README.md
```
